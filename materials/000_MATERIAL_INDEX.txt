RULES
1. Do not renumber an existing material after it is created.
2. IDs established in earlier materials must be reused by later materials.
3. Do not invent missing script content. Ambiguities are flagged for review.
4. Each material is validated before the next numbered material is started.
5. Application code is not part of this material sequence and is created only after the required materials are complete enough for implementation.
6. The final 002 Sentence-ID set and 003 Chunk-ID set are frozen after the 003 global release; any future source-proven correction must be documented and propagated transactionally.
