MEMORIZATION STAGES
M0_FULL
- Show the full authorized line text.
- Show translation/chunk/word/grammar help on request.
- Purpose: comprehension and first reading.

M1_CHUNK_GAPS
- Hide alternating semantic/grammatical chunks using frozen 003 chunk boundaries.
- Default deterministic mask: hide even-numbered chunks within each Sentence; if a Sentence has one chunk, hide that chunk only after the learner has left M0 at least once.
- Punctuation and layout are rendered from the canonical source layer; the mask does not alter canonical text.

M2_INITIAL_HINTS
- Hide the target wording and expose only minimal retrieval hints derived from chunk/word starts.
- The application may show first letters or first lexical words per chunk, but it must not require typed spelling.
- Hint generation is presentation logic; canonical Chunk IDs remain unchanged.

M3_HIDDEN
- Hide the target line completely.
- Learner recalls aloud or mentally.
- Optional microphone/speech-recognition support may display a transcript but must not be the sole correctness judge.

REVEAL
- Reveal restores the full authorized target line temporarily.
- Reveal never changes canonical data or memory IDs.
- After reveal, the learner self-rates the attempt.

SELF-ASSESSMENT
GOOD = 言えた
HARD = 少し怪しい
AGAIN = 言えなかった

The application stores the learner's own judgement. No keyboard-answer test or spelling score is required.

PROGRESS RECORD CONTRACT
One progress record per MEM-LINE unit may contain:
- speechId
- selectedCharacterId
- currentStage: M0_FULL | M1_CHUNK_GAPS | M2_INITIAL_HINTS | M3_HIDDEN
- lastRating: GOOD | HARD | AGAIN | NONE
- attempts
- reveals
- lastPracticedAt
- mastered: boolean

Optional Sentence/Chunk-level progress may be stored using MEM-SEN / MEM-CHK IDs, but line-level progress remains the minimum interoperable record.

STAGE ADVANCEMENT DEFAULT
- GOOD: may advance one memorization stage, capped at M3_HIDDEN.
- HARD: keep current stage.
- AGAIN: move back one stage when useful, floored at M0_FULL.
- Exact review dates are application policy and are not hard-coded into canonical material.

CUE PRACTICE
Source: 008 canonical adjacency graph.

- if previousSpeechId exists, cue = previousSpeechId
- if T is the first speech of a scene, cue = SCENE_START
- show cue/context first
- hide target according to its current memory stage
- reveal on request
- collect GOOD / HARD / AGAIN

REHEARSAL
- Traverse every canonical speech in scene order.
- If current speech belongs to the selected character: switch to YOUR TURN and apply memory-stage hiding.
- Otherwise: show the other character's line as cue/context; optional device TTS may read it.
- Stage directions may be shown as context from the authorized source layer but never become spoken memory targets.
- The rehearsal engine must consume canonical data and must not use historical embedded 008/009 prototype datasets as authority.

FOCUS / REVIEW ORDER
The application may prioritize targets in this order:
1. AGAIN
2. HARD
3. unseen / M0
4. GOOD not yet mastered
5. mastered
This is a UI/review ordering rule, not a change to canonical scene order.

MASTERED DEFAULT
A line may be marked mastered only after a GOOD result at M3_HIDDEN. The UI may allow the learner to clear or override progress manually.
