6. STRUCTURAL UNIT TYPES FOR 002
============================================================

002 classifies sequential script content using these structural types.

DIALOGUE
- Spoken text associated with one canonical speaker ID.
- May include a delivery/action cue attached to the speaker label or embedded in the turn.

STAGE_DIRECTION
- Bracketed or standalone dramatic action, movement, entrance, exit, lighting, sound, curtain, prop, or blocking direction.

SCENE_DESCRIPTION
- Opening location/time/set/state description belonging to a scene rather than a speaker.

SOUND_OR_MUSIC_CUE
- Non-dialogue sound/music event when represented as a distinct script event.
- If a sound description is embedded inside a larger stage direction, 002 may keep it inside that stage-direction unit rather than splitting it artificially.

CURTAIN_MARKER
- CURTAIN / QUICK CURTAIN or equivalent explicit scene-ending marker.

STRUCTURAL_HEADING
- Act heading, Scene heading, or source scene-setting heading.
- These are represented by 001 scene metadata and ordinarily are not duplicated as learning dialogue.

============================================================
7. STABLE UNIT ID CONVENTION
============================================================

Unit IDs are instantiated in 002 in strict source order inside each scene.

Format:
U-A{act2}-S{scene2}-{sequence4}

Examples of format only:
U-A01-S01-0001
U-A01-S01-0002
U-A01-S02-0001
U-A02-S01-0001

Rules:
- sequence4 starts at 0001 for each scene.
- Sequence follows source order, not speaker order.
- Once 002 is validated, a unit ID must never be reused for different source content.
- Later insertion caused by a proven extraction omission must not trigger casual renumbering. If insertion becomes necessary after downstream materials exist, use an explicit insertion suffix policy documented at that time.

============================================================

============================================================

Sentence IDs (002):

Vocabulary lemma IDs (005):

Exact normalization rules will be fixed in 005 before use.

Vocabulary occurrence IDs (006):
WUSE-{sentence_id}-{token_or_occurrence_sequence}
Exact token-sequence rules will be fixed in 006.

Context/translation/expression/memory files must reference the canonical IDs above rather than duplicating script text as their primary key.

============================================================
9. PAGE-BOUNDARY RULES FOR 002
============================================================

9.1 A PDF page break is not a dialogue/unit boundary by itself.
9.2 Wrapped dialogue continuing on the next physical page remains one dialogue unit if the source structure shows the same turn continuing.
9.3 Stage directions split by a page break remain within the same source span when they are grammatically/structurally continuous.
9.4 Printed page numbers, headers, and cover text are metadata and must not become dialogue units.
9.5 Scene boundaries defined in Section 3 always terminate the current scene sequence.
9.6 Speaker labels are preserved exactly as source labels in source_label fields; normalized display names are separate metadata.
